# 02 – Documentation Plan

## Nội dung
- Mô tả chi tiết từng tài liệu sẽ được viết trong thư mục `docs/`.
- Định dạng Markdown, bao gồm tiêu đề, mô tả, ví dụ API, hướng dẫn cài đặt.
- Mỗi tài liệu có mục **Mục tiêu**, **Nội dung**, **Ví dụ**, **Tham khảo**.
